刷之前想一下 记录与设置

数据与隐私

适用版本：0.8.3 · 更新日期：2026 年 10 月 14 日

本扩展会在你的浏览器中处理网站访问、计时和你主动填写的内容。它不是“完全不处理数据”的工具。公开版默认只在本机保存；没有内置广告、使用统计 SDK 或开发者运营的数据接收服务。

个人定制包例外：文件名以 -personal.zip 结尾的包可含授权预置的明文 WebDAV 连接信息，首次安装会自动启用设置和记录同步。不要公开这些文件。移除本机连接不会擦除安装文件里的凭据。

本机数据网络与同步安全边界保留与删除权限

本机处理和保存什么

  • 网站与设置：所选网站、自定义域名及名称、例外网址、台词、用途选项、离开网址、提醒和到期方式。精确例外可包含查询参数与片段，其中可能有私人信息。
  • 访问记录：受限网站的访问尝试、开始与结束时间、你选择或填写的用途、计划与经过时间、结束方式，以及短区间观测到的前台时间和按日汇总。前台观测不等于实际注意力或观看时间。
  • 临时导航信息：后台接收顶层页面导航事件，在内存中判断网址、当前文档和关联标签页。完整目标网址还用于会话状态及确认页地址；它不是已结束记录的字段。不相关网址不写入扩展的历史记录。Chrome 自身的历史和缓存不由本扩展代为清除。
  • 连接与设备信息：启用 WebDAV 时，在扩展本地存储保存服务器目录、用户名和密码；另保存随机设备 ID、同步版本、删除标记、最近状态及一份被同步替换的设置备份。设备 ID 用于区分同步文件，不用于广告追踪。
  • 每日自评：仅在你自愿开启后，保存你的定义、自估分钟、选择的回答、日期及提交和修改信息。自评不加入 WebDAV 或普通记录导出；单独导出需要明确确认。
  • 界面和会话状态：浮窗位置、收起状态、首次设置状态，以及正在进行的许可、截止时间和恢复状态。

保存的记录、设置、连接和自评位于当前浏览器配置的扩展本地存储。临时许可位于浏览器会话存储。不同电脑、不同浏览器配置默认不共享这些数据。

什么时候离开本机

公开版的 WebDAV 默认关闭。你启用并保存连接后，扩展通过 HTTPS 与你指定的服务器交换设置；勾选记录同步时，还交换已结束记录（含用途）、删除标记和同步版本。随机设备 ID 用于文件名。正在进行的许可、完整导航目标、浮窗位置和每日自评不参与同步。

服务器账号用于 HTTP 认证，不写入远端同步 JSON 或普通记录导出。同步不跟随重定向，也不携带网站 Cookie。你的服务器运营者可能收到网络地址、认证信息和请求日志，具体保留方式取决于该服务器。

打开目标网站或选择“离开”会发生正常的浏览器导航；默认离开网址为 Google，可自行修改。目标网站和 Chrome 按各自的方式处理这些访问，这不等于扩展向开发者上传了记录。扩展不读取 Cookie，不抓取网页正文、表单输入、聊天内容或视频内容用于记录或上传。

记录和自评只有在你点击相应导出操作时才生成为本地 JSON 文件。本版本没有自动提交反馈、研究回答或崩溃日志的服务。你随后主动分享文件，是一次独立的数据分享。

数据只用于你能看到的网站停顿、计时、个人回顾和自行开启的同步，不出售，不用于广告、信用评估或其他画像。开发者没有远程读取你本机或 WebDAV 数据的内置通道。

安全边界

WebDAV 仅接受 HTTPS，不跳过证书校验。扩展本地存储限制为扩展自身可信页面和后台访问，网页内的计时脚本不能直接读取连接凭据。

本版本没有应用层静态加密或端到端加密。本地保存的账号密码、浏览记录和自评，以及服务器上的同步 JSON，没有额外的应用层加密。能读取浏览器配置文件、安装文件或服务器数据的人可能访问它们。HTTPS 只保护传输，不能替代静态数据保护。

请使用可信设备和服务器，避免在用途或例外网址中填写秘密。个人包的预置密码不是加密保存；请勿上传到公开仓库或商店。浏览器崩溃、卸载、文件损坏或服务器故障仍可能造成数据丢失。

保留、更改和删除

  • 普通记录没有按时间自动清理。你可导出记录，或在“记录”页清除已结束记录；进行中的记录会保留。
  • 开启记录同步时，清除操作会传播删除标记，防止离线设备恢复旧记录。这不是安全擦除：尚未上线的设备、服务器旧快照和备份中可能仍有内容。
  • 关闭同步、取消记录同步或移除本机连接，不会自动删除已上传文件。远端文件、服务器日志及备份需由你按服务器提供的方式管理。
  • 自评最多保存 2000 天，达到上限会提示，不自动丢弃。关闭自评保留旧回答；可删除单日回答，或关闭并删除全部本机自评。已经导出的文件不会随之删除。
  • 设置和例外可随时修改。最近一份被远端替换的设置备份可能仍包含旧值，直到被后续备份替换或扩展本地数据被清除。

为什么需要这些权限

  • storage：保存上述本机设置、记录、连接及会话状态。
  • alarms：检查浏览时段到期和已启用的定时同步。
  • webNavigation：识别顶层导航、站内路由和相关标签页，在所选网站进入前显示确认页。
  • scripting：仅在已启用并获准的网站注入倒计时和暂停界面。
  • 可选的网站访问权限：由你所选的网站和填写的 WebDAV 服务器决定。声明可选域名范围不等于已获得全部网站权限。每台设备需分别授权；公开版没有默认必选主机权限。

版本与联系

这是一份随本地开发版提供的数据处理说明，本版本尚未公开上架，也没有内置客服或远程数据代管服务。公开发布前仍需确定发布者联系方式和公开隐私地址。请勿在公开反馈中粘贴密码、完整导出或含私人参数的网址。
