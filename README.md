# 刷之前想一下

让打开网站这件事多一个停顿。可以继续，但先选好要做什么、待多久；时间到了就关闭标签页。不打分，不限制重新申请。

## 在 Chrome 中试用

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录（里面有 `manifest.json`）。
3. 新开一个抖音、小红书或 Bilibili 页面。已经打开的页面需要刷新。
4. 点击浏览器工具栏中的插件图标，可以查看记录和设置。

不需要构建、不需要登录，也不用提供 Cookie。不要只双击 `pause.html`，它依赖扩展后台。ZIP 包先解压再加载；开发和测试使用源码目录。

## 当前规则

- 三个网站及其子域名全部限制。Bilibili 收藏播放列表暂不豁免。
- 确认页提供 5 / 10 / 15 分钟和自定义时长；用途可以选，也可以自己写。
- 放行只适用于当前标签页、当前网站。离开网站就结束这次许可。
- 从确认时开始计时，后台时间也算。默认最后 60 秒突出提醒，到期关闭标签页。
- 可以立即再次申请；没有冷却期、每日额度和专注日程。
- 「算了，离开」默认前往 Google，设置中可修改。台词、用途选项和提前提醒时间也可修改。

## 验收

选择「自定义」，填 `0.1` 分钟，可以用 6 秒检查倒计时和自动关页。再检查：

- 相同标签页内继续浏览，不再次确认；另开标签页需要确认。
- 点击离开，进入配置的网址。
- 记录页能看到用途、计划时长、实际时长和结束方式，并能导出 JSON。

## 数据与限制

记录和设置保存在 `storage.local`，临时许可在 `storage.session`。不上传数据，不读取 Cookie，不长期保存页面标题和完整网址。导出的用途仍可能包含个人信息。

计时记录的是这次许可经过的自然时间，不是观看时长。多标签页时间会累加；跨日访问归到申请当天。浏览器重启或插件重载后不继承许可，无法确认的中断时长显示为「未知」。

浏览器休眠、冻结或系统繁忙可能延迟关页；恢复运行后检查到期状态。它不是防绕过工具，也不会阻止你停用插件。请勿在有未保存内容的标签页中测试自动关页。

## 开发

```powershell
npm ci
npx playwright install chromium
npm test
npm run test:e2e
```

浏览器测试使用隔离的 Chromium 配置和模拟网站响应，不使用个人 Cookie。截图在 `test-results/`。测试没有覆盖三个网站的真实登录态和视频全屏场景。

打包：`powershell -ExecutionPolicy Bypass -File scripts/package.ps1`。交接见 [HANDOFF.md](HANDOFF.md)。
