# 刷之前想一下

让打开网站这件事多一个停顿。可以继续，但先选好要做什么、待多久；时间到了，暂停并重新选择。不打分，不限制重新申请。

## 安装到 Windows 或 Mac 的 Chrome

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录（里面有 `manifest.json`）。
3. 首次自动打开「网站」页，勾选需要停顿的网站，也可以添加域名。点击「保存并开始」，允许访问所选网站；也可选择「暂不启用」。
4. 点击浏览器工具栏中的插件图标，可以查看记录和设置。

Windows 和 Mac 使用同一个 ZIP，不需要编译或安装 Node.js。将 ZIP 解压到长期保留的目录，再加载其中包含 `manifest.json` 的文件夹；加载后不要删除或移动该目录。不要只双击 `pause.html`，它依赖扩展后台。Safari 不适用此安装方式。

仅本地使用不需要登录，也不用提供 Cookie。WebDAV 同步需要自行填写连接信息，默认关闭。

更新时覆盖原目录，在 `chrome://extensions` 点击本插件的「重新加载」，然后重新打开目标网址。不必卸载，原有设置和记录会保留；正在进行的许可会结束。

更新后，右上角应显示 `v0.8.1`。本版修复真实网站上倒计时浮窗变窄、文字竖排、按钮被挤出屏幕的问题；滚动条、窄屏和收起展开均按实际可见区域定位。

0.8.0 增加的本机每日自评仍默认关闭；它不改变你的限制规则，不自动收集回答，也不加入 WebDAV 同步。自定义域名、精确例外、前台观测、到期保留页面和同步继续保留。升级后在「网站」页检查本机授权；未授权的网站不拦截。

本版也修复了连续打开不同目标时，浏览器复用旧确认页导致按钮失效的问题。目标变化会重新初始化确认页；旧用途和时长不会被自动沿用到另一个目标。

## 网站与例外

首次安装不预选限制网站。可勾选抖音、小红书、Bilibili，或添加最多 30 个自定义域名。域名可以修改显示名称、选择是否包含子域名；不能填写公共后缀、IP、端口或带路径的网址。范围重叠时会提示修正规则。

例外最多 100 条，必须属于已经配置的网站：

- 「精确页面」匹配协议、主机、端口、路径、查询参数和片段；查询参数名顺序不影响匹配，但值必须相同。
- 「此路径及子路径」只放行该主机下的指定路径及其子路径，不限制查询参数和片段。例如 `https://www.bilibili.com/list/ml3197110280` 可放行这个列表的切歌参数，不会放行其他列表、其他主机或 `/list/ml31971102801`。
- 不允许把整个根路径设为例外；整站放行请关闭网站开关。路径中含编码分隔符的地址也不会被例外误放行。

保存时只请求所选网站的访问权限。同步来的规则不携带浏览器授权，每台设备需在「网站」页完成授权。关闭限制、添加当前页例外或移除授权会结束该页本机许可，但不关页、不刷新。重新启用后，从下一次导航开始检查，不会因为旧页面的心跳突然跳转。删除域名不会删除其历史记录；删除相关例外需确认。

## 到时之后

默认不再直接关页。到期会显示暂停对话框，保留当前文档和未提交的输入，暂停顶层页面的音视频，并将关联标签页静音。全屏文档会尝试退出全屏，显示对话框。到期方式可在「网站」或「设置」的「时间到了」中切换为「直接关闭关联标签页」。

- 「结束并关闭」关闭这次已到期访问的关联标签页；多个标签页先确认数量，不影响独立访问或已离站的页面。
- 「再安排一段时间」要求选择时长、确认用途，只恢复当前标签页。后台的关联标签页继续暂停。
- 「先保存内容 · 2 分钟」立即恢复当前页面两分钟，单独记录为保存内容时段，到期仍暂停，不自动关页。

恢复不会刷新页面，也不会自动播放刚刚暂停的视频；只撤销插件自身添加的静音，不撤销原有的用户静音。暂停对话框等待期间不增加已结束记录的前台时间；新选择的继续或保存内容时段正常计时和观测。「开始浏览」统计这些明确开始的时段，不是新建标签页的数量。

这是保留当前网页，不是备份或自动保存草稿。浏览器崩溃、丢弃标签页、网页自行重载、手动刷新或关闭，仍可能丢失内容。子框架播放器、封闭 Shadow DOM 或浏览器画中画可能不能被暂停，但标签页仍会被静音；不是强制防绕过工具。

尚未保存过到期方式的旧设置迁移为暂停。已有明确选择会保留。设置变更只影响后续开始的时段，不会在进行中突然改成关页。

## 有意识地开始，也能随时结束

打开受限网站时，确认页显示今天在该站已经进入的次数和已观测前台时间。两分钟内再次打开，会出现一个不带惩罚的提醒；你仍可离开或重新选择用途和时间。

浏览时，浮窗中的「结束并关闭」可以提前结束这次访问。不必等倒计时结束；有多个共享本次许可的标签页时，会先确认数量。仅关闭仍处于相应受限网站的关联标签页，不关闭无关页面。关闭前请先保存未完成内容。

「回顾」展示近 7 / 30 天的前台浏览、开始次数、打开前选择离开和主动结束次数。不设置连续打卡或分数，不把一次离开换算成猜测的“节省时间”。这是个人观察，不是已证明改善行为的研究结果。

## 可选的每日自评

在「回顾」底部展开「每日自评」，自行定义哪些浏览是你本来不想花时间的，再勾选同意并保存。每天可记录自估的非计划分钟、是否符合自己的打算、当天是否使用插件、是否转到其他设备继续刷，以及是否妨碍正事。没有通知或催填，也不会根据回答增加限制。

- 空白分钟是未知，不是零；不确定的回答单独计数，不冒充“没有问题”。
- 新回答只接受今天或昨天。已有回答可修正，首次提交、最后编辑日期和原有定义保留。
- 两期回顾比较的是已经结束的两周，今天不计入均值；数据不足或定义变化时显示相应状态。自估分钟不等于实际观测时长，不能理解为插件造成的节省。
- 自评只保存在当前浏览器配置的 `storage.local`，**即使个人包自动同步，它也不会上传到 WebDAV**。换电脑不会出现这些回答；跨设备情况由你在选定的一台电脑上统一自评。
- 「导出自评 JSON」与普通记录导出独立，需要确认。导出可能包含私人定义，请只主动分享给可信对象。
- 取消开启保留旧回答；可以单日删除，或关闭并删除全部本机自评。普通浏览记录、其他设备和已导出文件不会随之删除。最多保留 2000 天，达到上限报错，不自动清理。

可执行的个人试用步骤、缺失数据规则与只读分析命令见 `PILOT.md`。目前没有真实参与者效果数据，不能以本版功能或测试通过证明有效。

## 两台电脑同步

1. 先在有现有记录的电脑上升级，进入插件的「同步」页。
2. 勾选「启用自动同步」，填写完整的 HTTPS 同步目录、用户名和密码，例如 `https://dav.example.com/webdav/back-to-flow/`。不要填写管理页面地址或具体 JSON 文件地址。
3. 按需勾选「同步已结束的记录（含用途）」。只想同步设置时取消此项。
4. 点击「保存连接」，允许 Chrome 访问你填写的服务器，然后点击「立即同步」并确认成功。
5. Mac 上安装同一版本，填写相同目录和账号，保存连接并点击「立即同步」。个人定制包已预置连接，无需重新填写；同步后在「网站」页授权需要启用的网站。

启用后，每 5 分钟尝试同步一次；保存连接后首次自动尝试约在 30 秒后。浏览器关闭、休眠或网络离线时不会实时同步。错误会显示在同步页，本地拦截、计时和记录仍可使用。联网后自动重试，也可以手动重试。

同步范围与冲突处理：

- 网站开关、自定义域名、例外、台词、用途选项、离开网址、提醒时间及到期方式作为一份设置同步。不同设备同时编辑时，较新的设置版本胜出；若替换了本机设置，可用「恢复同步前设置」恢复最近一份旧设置。设备时钟应保持准确。
- 只同步已结束的记录；按唯一 ID 去重。正在进行的许可、标签页、倒计时和浮窗位置不跨设备同步。
- 清除已结束记录后，删除标记随记录同步传播，防止离线设备把旧记录恢复。开启同步前请先导出重要记录备份。
- 删除是逻辑删除：未再次上线的设备快照或服务器备份中可能仍有旧内容，不承诺安全擦除远端历史。
- 取消记录同步只停止本机参与记录合并，不删除已上传的历史。关闭同步或「移除本机连接」都不会删除服务器文件。
- 每个浏览器配置有自己的设备 ID，只写入自己的 `devices-v2/device-<ID>.json`，读取并合并其他设备文件。复制源码或 ZIP 即可，不要复制浏览器的用户数据目录。
- 首次同步会自动建立你指定的末级目录及 `devices-v2/` 子目录；其上级目录必须存在。账号需要目录列举、创建及文件读写权限。目录最多 32 个设备文件，合并后 JSON 上限 4 MB；到达限制时会报错而不是静默丢弃历史。这不是 Chrome 云同步的单项 8 KB 存储。

**两台电脑建议使用同一版本；从 0.6.x 升级时请一并升级。** 0.7.0 与 0.8.x 使用相同的 v2 同步协议。每台设备首次建立 v2 快照时会读取旧 `devices-v1/`，导入历史和删除标记，但绝不写回旧文件；已有 v2 设置优先于未编辑的旧版设置。之后旧版客户端的新改动不会持续桥接到 v2。升级前导出备份，先同步现有电脑，再安装或升级另一台。不要混用 v1 和 v2 版本长期同步。

## 隐私与连接

公开版中，服务器地址、账号和密码只保存在当前浏览器的扩展本地存储，不写入源码、发布包、记录导出或远端同步快照。内容脚本无权直接读取扩展本地存储。每台电脑都需要单独填写连接信息。

文件名以 `-personal.zip` 结尾的个人定制包例外：其中的 `install-defaults.js` 包含用户授权预置的明文连接信息，首次加载自动启用设置和记录同步，无需重新填写。已有本地连接优先，不会被预置值覆盖；手动关闭或移除连接后，也不会在重启时偷偷恢复。移除连接只清除浏览器保存的值，不会擦除安装文件里的预置凭据。个人包不能当成公开版分享。

连接仅接受 HTTPS，不跳过证书校验、不跟随重定向，也不携带网站 Cookie。公开版在保存连接时请求你指定服务器的可选主机权限；个人包已预授权其预置服务器。网站权限独立按所选域名申请，不申请所有网站的实际访问权限。

**本版本不提供端到端加密。** 密码在浏览器本地存储、记录在你的 WebDAV 服务器上都没有额外的应用层加密。服务器管理员和能读取浏览器配置文件的人可能访问这些数据。用途文字也可能包含私人信息，请使用可信服务器，最好使用限定目录权限的专用账号。

## 当前规则

- 只限制你已启用并在本机授权的网站。内置三站包含子域名，自定义站点范围和页面例外见上文。
- 确认页提供 5 / 10 / 15 分钟和自定义时长；用途可以选，也可以自己写。
- 从已放行页面点击同站链接打开新标签页，共用原来的用途和截止时间，不重复询问。继续从新标签页打开同站链接也一样。
- 独立新开网站、跨到另一个受限网站仍需确认。关闭或离开某个标签页，不影响这次浏览的其他页面；最后一个页面离开时结束记录。
- 从确认时开始计时，后台时间也算。默认最后 60 秒突出提醒，到期暂停这次浏览中仍在该网站的所有标签页；选择直接关闭时才会关页。
- 倒计时左侧手柄可以拖动，右侧按钮可以收起；收起后仍显示剩余时间。位置和收起状态保存在本地，刷新和后续打开页面时沿用。
- 可以立即再次申请；没有冷却期、每日额度和专注日程。
- 「算了，离开」默认前往 Google，设置中可修改。台词、用途选项和提前提醒时间也可修改。

## 验收

选择「自定义」，填 `0.1` 分钟，可以用 6 秒检查倒计时和到期暂停。使用测试内容，不要用重要的未保存工作。再检查：

- 站内链接新开标签页不再次确认、不重新计时；独立新开网站仍需确认。
- 拖动、收起倒计时，再刷新页面和缩小窗口，检查位置与可见性。
- 从普通网页和第三方新标签页点击进入，都能看到可操作的确认页。
- 点击离开，进入配置的网址。
- 记录页能看到用途、计划时长、实际时长和结束方式，并能导出 JSON。
- 到期后，页面中的测试输入仍在；重新选择时长或保存内容不会刷新页面，暂停关联页不会全部恢复。
- 在设置中选择直接关闭后，新开始的访问到期关页；切换方式不改变已经开始的访问。

## 数据与限制

记录和设置保存在 `storage.local`，临时许可在 `storage.session`。公开版默认不上传数据；启用 WebDAV 后，按选定范围同步到自己的服务器。不读取 Cookie，浏览历史不长期保存页面标题和完整网址。你主动配置的例外网址属于设置，会保存并同步，精确页面的查询参数也在其中。用途和例外均可能包含个人信息。

「经过」记录的是这次浏览经过的自然时间，不是观看时长。「前台」从 0.5.0 开始单独观测：仅在聚焦的浏览器窗口、活动标签页和可见文档之间累计短区间。后台页面不计入，超过 15 秒的采样间隔不补算。该数据不证明人在观看，也无法区分屏幕前走神或短时间离开。

前台采样通常每 5 秒一次，先保存在浏览器会话内存，切换页面、离开窗口、结束访问时落盘，持续浏览时约每 30 秒检查落盘。worker 重启会恢复会话中的最新样本；浏览器崩溃或操作系统强制退出可能丢失尚未落盘的尾部样本，不会凭空补齐。

旧版记录没有前台数据，显示为「未观测」，不能与新指标直接比较。同一次浏览派生的标签页只记一次访问，不重复累计同一时段。访问次数归到申请当天，前台区间按观测设备的本地日历日期拆分；跨时区设备的日期口径可能不同。浏览器重启或插件重载后不继承许可，无法确认的中断经过时间显示为「未知」。

浏览器休眠、冻结或系统繁忙可能延迟暂停或关页；恢复运行后检查到期状态。它不是防绕过工具，也不会阻止你停用插件。请勿在有未保存内容的标签页中测试自动关页。

导航监听不是网络防火墙：目标网页可能先发出请求或短暂显示，再被切换到确认页。访问尝试在后台跳转前写入，不依赖确认页脚本成功加载；跳转或确认页文档加载失败时，记录显示「确认页跳转失败」。
