# 刷之前想一下

让打开网站这件事多一个停顿。可以继续，但先选好要做什么、待多久；时间到了就关闭标签页。不打分，不限制重新申请。

## 安装到 Windows 或 Mac 的 Chrome

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录（里面有 `manifest.json`）。
3. 新开一个抖音、小红书或 Bilibili 页面。已经打开的页面需要刷新。
4. 点击浏览器工具栏中的插件图标，可以查看记录和设置。

Windows 和 Mac 使用同一个 ZIP，不需要编译或安装 Node.js。将 ZIP 解压到长期保留的目录，再加载其中包含 `manifest.json` 的文件夹；加载后不要删除或移动该目录。不要只双击 `pause.html`，它依赖扩展后台。Safari 不适用此安装方式。

仅本地使用不需要登录，也不用提供 Cookie。WebDAV 同步需要自行填写连接信息，默认关闭。

更新时覆盖原目录，在 `chrome://extensions` 点击本插件的「重新加载」，然后重新打开目标网址。不必卸载，原有设置和记录会保留；正在进行的许可会结束。

更新后，记录页右上角应显示 `v0.4.0`。这一版新增可配置 WebDAV 同步、记录合并与删除同步，以及三个网站的独立开关。

## 两台电脑同步

1. 先在有现有记录的电脑上升级，进入插件的「同步」页。
2. 勾选「启用自动同步」，填写完整的 HTTPS 同步目录、用户名和密码，例如 `https://dav.example.com/webdav/back-to-flow/`。不要填写管理页面地址或具体 JSON 文件地址。
3. 按需勾选「同步已结束的记录（含用途）」。只想同步设置时取消此项。
4. 点击「保存连接」，允许 Chrome 访问你填写的服务器，然后点击「立即同步」并确认成功。
5. Mac 上安装同一版本，填写相同目录和账号，保存连接并点击「立即同步」。

启用后，每 5 分钟尝试同步一次；保存连接后首次自动尝试约在 30 秒后。浏览器关闭、休眠或网络离线时不会实时同步。错误会显示在同步页，本地拦截、计时和记录仍可使用。联网后自动重试，也可以手动重试。

同步范围与冲突处理：

- 网站开关、台词、用途选项、离开网址及提醒时间作为一份设置同步。不同设备同时编辑时，较新的设置版本胜出；若替换了本机设置，可用「恢复同步前设置」恢复最近一份旧设置。设备时钟应保持准确。
- 只同步已结束的记录；按唯一 ID 去重。正在进行的许可、标签页、倒计时和浮窗位置不跨设备同步。
- 清除已结束记录后，删除标记随记录同步传播，防止离线设备把旧记录恢复。开启同步前请先导出重要记录备份。
- 删除是逻辑删除：未再次上线的设备快照或服务器备份中可能仍有旧内容，不承诺安全擦除远端历史。
- 取消记录同步只停止本机参与记录合并，不删除已上传的历史。关闭同步或「移除本机连接」都不会删除服务器文件。
- 每个浏览器配置有自己的设备 ID，只写入自己的 `devices-v1/device-<ID>.json`，读取并合并其他设备文件。复制源码或 ZIP 即可，不要复制浏览器的用户数据目录。
- 首次同步会自动建立你指定的末级目录及 `devices-v1/` 子目录；其上级目录必须存在。账号需要目录列举、创建及文件读写权限。目录最多 32 个设备文件，合并后 JSON 上限 4 MB；到达限制时会报错而不是静默丢弃历史。

## 隐私与连接

公开版中，服务器地址、账号和密码只保存在当前浏览器的扩展本地存储，不写入源码、发布包、记录导出或远端同步快照。内容脚本无权直接读取扩展本地存储。每台电脑都需要单独填写连接信息。

文件名以 `-personal.zip` 结尾的个人定制包例外：其中的 `install-defaults.js` 包含用户授权预置的明文连接信息，首次加载自动启用设置和记录同步，无需重新填写。已有本地连接优先，不会被预置值覆盖；手动关闭或移除连接后，也不会在重启时偷偷恢复。移除连接只清除浏览器保存的值，不会擦除安装文件里的预置凭据。个人包不能当成公开版分享。

连接仅接受 HTTPS，不跳过证书校验、不跟随重定向，也不携带网站 Cookie。只在保存连接时请求你指定服务器的可选主机权限；默认不会访问任意其他网站。

**本版本不提供端到端加密。** 密码在浏览器本地存储、记录在你的 WebDAV 服务器上都没有额外的应用层加密。服务器管理员和能读取浏览器配置文件的人可能访问这些数据。用途文字也可能包含私人信息，请使用可信服务器，最好使用限定目录权限的专用账号。

## 当前规则

- 默认限制抖音、小红书、Bilibili 及各自子域名，可在设置中独立关闭。关闭限制会结束该站的本机许可但不关页。此版不支持添加任意域名或 URL 例外；Bilibili 收藏播放列表暂不豁免。
- 确认页提供 5 / 10 / 15 分钟和自定义时长；用途可以选，也可以自己写。
- 从已放行页面点击同站链接打开新标签页，共用原来的用途和截止时间，不重复询问。继续从新标签页打开同站链接也一样。
- 独立新开网站、跨到另一个受限网站仍需确认。关闭或离开某个标签页，不影响这次浏览的其他页面；最后一个页面离开时结束记录。
- 从确认时开始计时，后台时间也算。默认最后 60 秒突出提醒，到期关闭这次浏览中仍在该网站的所有标签页。
- 倒计时左侧手柄可以拖动，右侧按钮可以收起；收起后仍显示剩余时间。位置和收起状态保存在本地，刷新和后续打开页面时沿用。
- 可以立即再次申请；没有冷却期、每日额度和专注日程。
- 「算了，离开」默认前往 Google，设置中可修改。台词、用途选项和提前提醒时间也可修改。

## 验收

选择「自定义」，填 `0.1` 分钟，可以用 6 秒检查倒计时和自动关页。再检查：

- 站内链接新开标签页不再次确认、不重新计时；独立新开网站仍需确认。
- 拖动、收起倒计时，再刷新页面和缩小窗口，检查位置与可见性。
- 从普通网页和第三方新标签页点击进入，都能看到可操作的确认页。
- 点击离开，进入配置的网址。
- 记录页能看到用途、计划时长、实际时长和结束方式，并能导出 JSON。

## 数据与限制

记录和设置保存在 `storage.local`，临时许可在 `storage.session`。默认不上传数据；启用 WebDAV 后，按选定范围同步到自己的服务器。不读取 Cookie，不长期保存页面标题和完整网址。导出的用途仍可能包含个人信息。

计时记录的是这次浏览经过的自然时间，不是观看时长。同一次浏览派生的标签页只记一次访问和耗时，不累加；各自独立申请的访问仍分别统计。跨日访问归到申请当天。浏览器重启或插件重载后不继承许可，无法确认的中断时长显示为「未知」。

浏览器休眠、冻结或系统繁忙可能延迟关页；恢复运行后检查到期状态。它不是防绕过工具，也不会阻止你停用插件。请勿在有未保存内容的标签页中测试自动关页。

导航监听不是网络防火墙：目标网页可能先发出请求或短暂显示，再被切换到确认页。访问尝试在后台跳转前写入，不依赖确认页脚本成功加载；跳转或确认页文档加载失败时，记录显示「确认页跳转失败」。

## 开发

```powershell
npm ci
npm run vendor
npx playwright install chromium
npm test
npm run test:e2e
npm run test:upgrade
npm run test:sync
npm run test:personal
```

浏览器测试使用隔离的 Chromium 配置和模拟网站响应，不使用个人 Cookie。同步浏览器测试使用两个独立配置与模拟 WebDAV，覆盖同步、离线重试、删除和密码保存。升级测试在临时目录模拟旧版 DNR 规则、保留数据并原地重载。截图在 `test-results/`。测试没有覆盖真实 Mac、你的实际 Chrome 配置、三个网站的真实登录态和视频全屏场景。

WebDAV XML 使用 `@rgrove/parse-xml` 5.0.0 的浏览器构建。固定版本的副本与 ISC 许可证放在 `vendor/`，发布包不需要联网下载依赖。`npm run vendor` 可从锁定的 npm 依赖重新生成副本。

打包：`pwsh -ExecutionPolicy Bypass -File scripts/package.ps1`。交接见 [HANDOFF.md](HANDOFF.md)。

个人定制打包：临时提供环境变量 `BTF_WEBDAV_URL`、`BTF_WEBDAV_USERNAME`、`BTF_WEBDAV_PASSWORD`，运行同一打包命令并加上 `-Personal`。脚本只在个人 ZIP 内替换预置模块并增加指定主机权限，不修改源码中的空预置，也不把凭据写入公开包。ZIP 文件已被 Git 忽略。
